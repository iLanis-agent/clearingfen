# Clearingfen 1.0 TEST
Native Java/Canvas Android 8+ Akichiwake white-clearing puzzle.

Shade any cells, including cells carrying room clues. Dark cells cannot share an edge, and all white cells must remain one edge-connected area. Each room clue is an upper limit on the size of every connected white group within that room, not an exact shade count; the limit need not be reached. A straight consecutive white run cannot cross more than one room border. Tap a cell to shade or restore it. Twelve unique 4x4 rectangular-room boards have twelve distinct solutions. Every room is numbered in this edition.

Saved clearing palette and room guides, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, account or requested permissions. Settings and completed-puzzle marks stay on device. External studio link opens browser.

Independent Java uses coordinate-set components for global white connectivity and each room, pairwise dark-cell adjacency and every same-row/column white endpoint pair for border crossings. All 65536 complete shadings per board agree with production bitset floods and straight-ray transitions. Exactly one solution per board; bounds, solve, undo and replay pass. Adapter navigation, saved settings, privacy, cell taps, next, levels and persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only; not final or Play published.

Current 803-entry registry, 123 partial recovered README records and exact Strokehaven cumulative stage found no Akichiwake or room-white-component-cap match. Shares Roomhaven Heyawake shading, isolated dark cells, connected white and room-border white-run limits, but replaces exact per-room dark quotas with upper bounds on the size of each within-room white component. A limit need not be attained. This changes the target and component algorithm, not only the presentation. Unlike Mossreach Aqre, dark cells do not connect and there is no symmetric four-run cap. Known Akichiwake variant, not a global invention. Partial recovered corpus, not ALL-local. Rules https://shyeheya.wixsite.com/shyesstuff/post/132-akichiwake .
